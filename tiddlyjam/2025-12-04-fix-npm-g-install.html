2025-12-04 fix npm -g install

我终于解决了 node.js 版本切换时全局安装的 CLI 失效的问题，一次安装，一直可用。🎉

同时也解决了相同 CLI 在不同 node.js 版本下重复安装的问题。🎊

rm -rvf /Users/tj/.nvm/
rm -rvf /Users/tj/.volta
rm -rvf /opt/homebrew/lib/node_modules
rm -rvf /Users/tj/.cache/pnpm/dlx 
rm -rvf /Users/tj/.npm/_npx/
rm -rvf /Users/tj/.npm/

在删除了 node.js 各种版本中的历史垃圾以后，我的电脑空间瞬间就不紧张了。🥳

How

我使用 mise 代替 npm -g 。

- npm -g install tiddlywiki
+ mise use -g npm:tiddlywiki
