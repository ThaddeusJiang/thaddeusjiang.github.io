# Repository Instructions

## Non-technical articles

- Manage non-technical articles under `not-dev/`.
- Store articles as Markdown files with the `.md` extension.
- Use `not-dev/draft/` for Chinese drafts.
- Use `not-dev/draft-ja/` for Japanese drafts.
- Use `not-dev/published-ja/` for finalized Japanese articles.
- Treat the article flow as `draft` -> `draft-ja` -> `published-ja`.
- The location for finalized Chinese articles is undecided. Do not create one without confirmation.
